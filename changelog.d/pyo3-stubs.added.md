Fully typed Python API: `xenosite.forest._rust.pyi` is generated from the Rust bindings with pyo3-stub-gen (`make stubs`, drift-checked in CI), and the package ships `py.typed`. Dict returns (`to_dict()`, `hops()`, `maybe()`, `missed()`, …) are `TypedDict`s generated from the same Rust structs that build them, and are importable at runtime from `xenosite.forest._rust`. The generator lives behind the dev-only `stubs` Cargo feature and is not compiled into wheels.
